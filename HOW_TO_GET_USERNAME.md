# How to Retrieve PCL External Login Username

## Question
You have software that wants to directly use the username generated by PCL's external login.

## Encryption Method

PCL uses **DES (Data Encryption Standard)** encryption algorithm to protect sensitive data in the registry.

### Encryption Parameters
- **Algorithm**: DES
- **Key**: Fixed 8-byte key `"00000000"` (in open source version)
- **Initialization Vector (IV)**: `"87160295"`
- **Encoding**: UTF-8
- **Output Format**: Base64

### Code Implementation
Encryption and decryption code is located in `Plain Craft Launcher 2/Modules/ModSecret.vb`:

```vb
' Encryption function
Friend Function SecretEncrypt(SourceString As String, Optional Key As String = "") As String
    Key = SecretKeyGet(Key)  ' Returns "00000000"
    Dim btKey As Byte() = Encoding.UTF8.GetBytes(Key)
    Dim btIV As Byte() = Encoding.UTF8.GetBytes("87160295")
    Dim des As New DESCryptoServiceProvider
    Using MS As New MemoryStream
        Dim inData As Byte() = Encoding.UTF8.GetBytes(SourceString)
        Using cs As New CryptoStream(MS, des.CreateEncryptor(btKey, btIV), CryptoStreamMode.Write)
            cs.Write(inData, 0, inData.Length)
            cs.FlushFinalBlock()
            Return Convert.ToBase64String(MS.ToArray())
        End Using
    End Using
End Function

' Decryption function
Friend Function SecretDecrypt(SourceString As String, Optional Key As String = "") As String
    Key = SecretKeyGet(Key)  ' Returns "00000000"
    Dim btKey As Byte() = Encoding.UTF8.GetBytes(Key)
    Dim btIV As Byte() = Encoding.UTF8.GetBytes("87160295")
    Dim des As New DESCryptoServiceProvider
    Using MS As New MemoryStream
        Dim inData As Byte() = Convert.FromBase64String(SourceString)
        Using cs As New CryptoStream(MS, des.CreateDecryptor(btKey, btIV), CryptoStreamMode.Write)
            cs.Write(inData, 0, inData.Length)
            cs.FlushFinalBlock()
            Return Encoding.UTF8.GetString(MS.ToArray())
        End Using
    End Using
End Function
```

## Username Storage Location

Usernames are stored in the Windows Registry at:
```
HKEY_CURRENT_USER\Software\PCLDebug\
```

### Available Username Keys

Depending on the login type, usernames are stored in different registry keys:

#### Nide8 Unified Passport
- **CacheNideName** - Display name (name shown in-game)
- **CacheNideUsername** - Account username

#### Authlib-Injector
- **CacheAuthName** - Display name (name shown in-game)
- **CacheAuthUsername** - Account username

**Recommended to use `CacheNideName` or `CacheAuthName`** as these are typically the in-game display names.

## How to Retrieve Username in Your Software

### Method 1: Using C# Code

```csharp
using System;
using System.IO;
using System.Security.Cryptography;
using System.Text;
using Microsoft.Win32;

public class PCLUserNameReader
{
    // DES decryption function
    private static string DecryptDES(string encryptedString)
    {
        byte[] key = Encoding.UTF8.GetBytes("00000000");
        byte[] iv = Encoding.UTF8.GetBytes("87160295");
        
        using (DESCryptoServiceProvider des = new DESCryptoServiceProvider())
        using (MemoryStream ms = new MemoryStream())
        {
            byte[] inputData = Convert.FromBase64String(encryptedString);
            using (CryptoStream cs = new CryptoStream(ms, des.CreateDecryptor(key, iv), CryptoStreamMode.Write))
            {
                cs.Write(inputData, 0, inputData.Length);
                cs.FlushFinalBlock();
                return Encoding.UTF8.GetString(ms.ToArray());
            }
        }
    }
    
    // Read and decrypt username from registry
    public static string GetNideUserName()
    {
        try
        {
            using (RegistryKey key = Registry.CurrentUser.OpenSubKey(@"Software\PCLDebug"))
            {
                if (key != null)
                {
                    string encryptedName = key.GetValue("CacheNideName") as string;
                    if (!string.IsNullOrEmpty(encryptedName))
                    {
                        return DecryptDES(encryptedName);
                    }
                }
            }
        }
        catch (Exception ex)
        {
            Console.WriteLine($"Read failed: {ex.Message}");
        }
        return null;
    }
    
    // Get Authlib-Injector username
    public static string GetAuthlibUserName()
    {
        try
        {
            using (RegistryKey key = Registry.CurrentUser.OpenSubKey(@"Software\PCLDebug"))
            {
                if (key != null)
                {
                    string encryptedName = key.GetValue("CacheAuthName") as string;
                    if (!string.IsNullOrEmpty(encryptedName))
                    {
                        return DecryptDES(encryptedName);
                    }
                }
            }
        }
        catch (Exception ex)
        {
            Console.WriteLine($"Read failed: {ex.Message}");
        }
        return null;
    }
    
    // Auto-detect and return available username
    public static string GetUserName()
    {
        string username = GetNideUserName();
        if (!string.IsNullOrEmpty(username))
            return username;
        
        username = GetAuthlibUserName();
        if (!string.IsNullOrEmpty(username))
            return username;
        
        return null;
    }
}

// Usage example
class Program
{
    static void Main()
    {
        string username = PCLUserNameReader.GetUserName();
        if (username != null)
        {
            Console.WriteLine($"Username: {username}");
        }
        else
        {
            Console.WriteLine("Username not found");
        }
    }
}
```

### Method 2: Using Python Code

```python
import winreg
import base64
from Crypto.Cipher import DES
from Crypto.Util.Padding import unpad

def decrypt_des(encrypted_string):
    """Decrypt DES encrypted string"""
    key = b'00000000'
    iv = b'87160295'
    
    cipher = DES.new(key, DES.MODE_CBC, iv)
    encrypted_data = base64.b64decode(encrypted_string)
    decrypted_data = cipher.decrypt(encrypted_data)
    
    # Remove PKCS7 padding
    try:
        decrypted_data = unpad(decrypted_data, DES.block_size)
    except ValueError:
        pass
    
    return decrypted_data.decode('utf-8')

def get_username_from_registry(key_name):
    """Read and decrypt username from registry"""
    try:
        key = winreg.OpenKey(winreg.HKEY_CURRENT_USER, r"Software\PCLDebug")
        encrypted_name, _ = winreg.QueryValueEx(key, key_name)
        winreg.CloseKey(key)
        
        if encrypted_name:
            return decrypt_des(encrypted_name)
    except Exception as e:
        print(f"Read failed: {e}")
    return None

def get_pcl_username():
    """Get PCL external login username"""
    # Try Nide8 first
    username = get_username_from_registry("CacheNideName")
    if username:
        return username
    
    # Try Authlib-Injector
    username = get_username_from_registry("CacheAuthName")
    if username:
        return username
    
    return None

# Usage example
if __name__ == "__main__":
    username = get_pcl_username()
    if username:
        print(f"Username: {username}")
    else:
        print("Username not found")
```

### Method 3: Using PowerShell Script

```powershell
# DES decryption function
function Decrypt-DES {
    param(
        [string]$EncryptedString
    )
    
    $key = [System.Text.Encoding]::UTF8.GetBytes("00000000")
    $iv = [System.Text.Encoding]::UTF8.GetBytes("87160295")
    
    $des = New-Object System.Security.Cryptography.DESCryptoServiceProvider
    $des.Key = $key
    $des.IV = $iv
    $des.Mode = [System.Security.Cryptography.CipherMode]::CBC
    
    $encryptedBytes = [System.Convert]::FromBase64String($EncryptedString)
    $decryptor = $des.CreateDecryptor()
    
    $ms = New-Object System.IO.MemoryStream
    $cs = New-Object System.Security.Cryptography.CryptoStream($ms, $decryptor, [System.Security.Cryptography.CryptoStreamMode]::Write)
    
    $cs.Write($encryptedBytes, 0, $encryptedBytes.Length)
    $cs.FlushFinalBlock()
    
    $decryptedBytes = $ms.ToArray()
    $decryptedString = [System.Text.Encoding]::UTF8.GetString($decryptedBytes)
    
    $cs.Close()
    $ms.Close()
    
    return $decryptedString
}

# Get username from registry
function Get-PCLUserName {
    $regPath = "HKCU:\Software\PCLDebug"
    
    # Try reading Nide8 username
    try {
        $encryptedName = Get-ItemPropertyValue -Path $regPath -Name "CacheNideName" -ErrorAction Stop
        if ($encryptedName) {
            return Decrypt-DES -EncryptedString $encryptedName
        }
    } catch {
        Write-Host "Nide8 username not found"
    }
    
    # Try reading Authlib username
    try {
        $encryptedName = Get-ItemPropertyValue -Path $regPath -Name "CacheAuthName" -ErrorAction Stop
        if ($encryptedName) {
            return Decrypt-DES -EncryptedString $encryptedName
        }
    } catch {
        Write-Host "Authlib username not found"
    }
    
    return $null
}

# Usage example
$username = Get-PCLUserName
if ($username) {
    Write-Host "Username: $username"
} else {
    Write-Host "Username not found"
}
```

## Important Notes

1. **Open Source Version Limitation**: The above code is based on PCL's open source version, which uses a fixed key `"00000000"`. The official version may use a different key generation method.

2. **Security**: The DES algorithm is considered insecure, but since this is only for local data protection, the risk is relatively low.

3. **Permissions**: Your software needs permission to read the current user's registry.

4. **Check for null values**: If the user hasn't logged in yet, the corresponding registry keys may not exist or be empty.

5. **Choose the correct key**:
   - If your users use Nide8 Unified Passport, read `CacheNideName`
   - If your users use Authlib-Injector, read `CacheAuthName`
   - For compatibility, try reading both

6. **UUID vs Display Name**:
   - `CacheNideName` / `CacheAuthName` - In-game display name (recommended)
   - `CacheNideUuid` / `CacheAuthUuid` - Player UUID (unique identifier)
   - `CacheNideUsername` / `CacheAuthUsername` - Login account name

## Registry Key Reference

| Key Name | Description | Purpose |
|----------|-------------|---------|
| CacheNideName | Nide8 display name | **In-game display name (recommended)** |
| CacheNideUsername | Nide8 account name | Login account |
| CacheNideUuid | Nide8 UUID | Player unique identifier |
| CacheAuthName | Authlib display name | **In-game display name (recommended)** |
| CacheAuthUsername | Authlib account name | Login account |
| CacheAuthUuid | Authlib UUID | Player unique identifier |

## Complete Process

1. Open registry path `HKEY_CURRENT_USER\Software\PCLDebug\`
2. Read the value of `CacheNideName` or `CacheAuthName` (Base64 encoded encrypted string)
3. Decrypt using DES (key: `"00000000"`, IV: `"87160295"`)
4. Get the plaintext username

## Example

If the registry value for `CacheNideName` is:
```
kRz8YnBmGXk=
```

After decryption, you get:
```
Steve
```

This is the user's in-game display name.

## Summary

You only need to:
1. Read registry `HKEY_CURRENT_USER\Software\PCLDebug\CacheNideName` or `CacheAuthName`
2. Decrypt using DES algorithm (key: `"00000000"`, IV: `"87160295"`)
3. Get the username

Use the code examples provided above to implement this functionality directly in your software.
